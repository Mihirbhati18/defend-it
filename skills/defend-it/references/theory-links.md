# Theory links

Vivas often jump from the project to a core subject. Find spots in the student's code that connect to these, and ask about them. Always tie the question to their code: *"Your `users` table — which normal form is it in?"* not just *"What is 3NF?"*

## DBMS
| If the project has... | Ask about |
|---|---|
| SQL tables | keys (primary, foreign), normalization (1NF–3NF), joins |
| Multiple related writes | transactions, ACID, what if it fails halfway |
| Booking / stock / money | concurrency, locking, race conditions |
| Search / filters | indexes, why queries get slow |
| MongoDB / Firebase | SQL vs NoSQL, when each fits, schema design |

## OOP
| If the project has... | Ask about |
|---|---|
| Classes / models | encapsulation, constructors, access modifiers |
| Base + child classes | inheritance, method overriding, polymorphism |
| Interfaces / abstract classes | abstraction, why use an interface |
| Repeated code | DRY, how they'd refactor it |

## DSA
| If the project has... | Ask about |
|---|---|
| Loops over lists | time complexity, Big-O |
| Searching / sorting | which algorithm, why, complexity |
| Maps / dictionaries / sets | hashing, why O(1) lookup |
| Graphs / routes / recommendations | BFS/DFS, Dijkstra, how the logic picks results |
| Queues / scheduling | queue vs stack, priority queue |

## Operating systems
| If the project has... | Ask about |
|---|---|
| Async code, threads, workers | process vs thread, concurrency, deadlock |
| File uploads / storage | file systems, where files live |
| Background jobs / cron | scheduling |

## Computer networks
| If the project has... | Ask about |
|---|---|
| REST APIs | HTTP methods, status codes, request/response |
| Login / sessions | cookies vs tokens, HTTPS, what TLS protects |
| Real-time chat / live updates | WebSockets vs polling |
| Deployment | DNS, ports, client-server model |

## Software engineering
| Always | Ask about |
|---|---|
| Any project | SDLC model used, requirements, testing types (unit / integration), version control |
| Team project | how work was divided, Git branching, merge conflicts |

## ML / AI projects
| If the project has... | Ask about |
|---|---|
| A trained model | dataset source and size, train/test split, overfitting, which metric and why |
| Accuracy numbers | how measured, on what data, confusion matrix, precision vs recall |
| An LLM / API call | what the API does, cost, what happens if it's down, prompt design |
| "AI" that is rules | be honest: is it really ML? (common viva trap) |
